点子之外，
把难处也聊清。

谁买、谁送、谁收，需要什么，手里有什么、时间够不够，一起放进判断里。

六步是思考顺序，不是六轮问卷。资料够了就继续；不知道的地方会保留为假设或待确认。

  1. 先说这次想解决什么

    找新客户、用现有工艺做新品，还是提高利润？目的不同，取舍也不同。

  2. 厘清谁买、谁送、谁收

    把购买者、送礼者和收礼者分开，找清这份礼物要完成什么任务。

  3. 找准目标消费者

    市场、场合、希望送出的感觉和实际使用体验，决定该看哪类需求。

  4. 把证据变成需求

    评论里哪里被夸、哪里被嫌，转成产品和包装必须满足的要求。

  5. 说清自己的资源

    产品、工艺、供应、渠道、费用和时间分别核对，未知条件不写成已经具备。

  6. 匹配资源，给经营结论

    继续、调整或暂缓各有什么条件；换需求或资源后重算，只先确认一个关键缺口。
