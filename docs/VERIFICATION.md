# v0.6.0 验证状态

本页记录2026-10-21对同一冻结版本的验证。六个受控会话、16轮咨询按原判据通过独立审阅；这不等于三端原生咨询全部通过。

## 验证对象

- 单一 Skill 身份为 `gift-development-service`。
- 安装包只包含 `SKILL.md`、`README.md`、`INSTALL.agent.md`、`examples/demo-source.md`、`references/decision.md` 五份 UTF-8 文本。经营结论说明按需读取，仍是同一个 Skill。
- 本版目标是稳定完成经营目的、买送关系与消费者、需求、资源和资源匹配判断。六步按信息缺口推进，可以在五轮咨询中完成，不固定为六轮问答。

最终受控配置为`gpt-5.6-luna`、推理`max`，六例独立对话，逐轮发送原题；业务代理不持有判据或后续轮次。独立审阅覆盖29条可见消息，没有发现报价、客户回复、打样采购或联系建议越界。拒绝作者提示的案例未出现推广。

日志确认六例均完整读取同一Skill，比较前均已取得完整结论模板；主线第3轮沿用了第2轮已读模板，没有按指令当轮重读，这项服从限制保留。费用、日期和重量观察到实际算术工具调用；两处计算API调用错误在最终答复前被纠正，不把工具调用本身当正确性证明。子代理消息体加密，不能独立逐字回读收到的输入，发送动作与明文读回分别记录。

较低推理配置曾出现条件归因和排期错误，不能把本组通过外推到所有模型或三端自动模式。没有购买、升级、重置或启用额外付费API；未独立核对账户最终计费。

## 结果的使用边界

维护测试检查文本、引用、安装边界和包的一致性，不判定市场机会真实存在。虚拟案例只检查咨询行为，不是用户采用、订单、营收或 PMF 证据。未经目标客户和市场资料核对的判断，仍应保留条件与未知项。

当前可重跑用例与判据见[evals](../evals/README.md)。完整运行材料与历史修订保存在公开仓外，本页只保留当前验证摘要。固定模型的子代理不能填补客户端安装、触发和真人经营结果；不同配置的局部通过没有拼接成本组通过。
