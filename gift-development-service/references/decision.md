# 本轮经营结论

只使用本次目的、用户选定基线和当前判断卡。不默认投入，不报价、回复客户、安排打样采购或联系。这个模板不授权任何执行。

**先接续事实。** 逐项对应当前要求、所给对象与范围、已有依据和本轮变化，只改被新信息影响的状态。用户已明确给定的结果注明“用户提供”或“虚拟给定”，在该范围内沿用；没有额外实测不构成撤回理由。未知须对应本次目的、原要求或已有评论，不临时新增“整体是否合适”等笼统门槛。一个条件未知不能推翻另一项已有依据的结果。

**再核完整时间式。** 先按明确依赖写各路径的完成式，再写尚未化简、带括号的E。路径内缓冲只归该路径；所有路径完成后统一增加的阶段或缓冲必须放在并行最晚值外：`E=max(路径一,路径二,…)+统一末尾阶段及缓冲`。每个已给时长和缓冲都有归属，未知量保留为符号。先核原式覆盖全部依赖，再用已有计算工具核数，最后由同一个E推导余量和购买覆盖。

结论留下四项，可合并进判断卡。短答也不能删去最后的改判分支：

1. **优先方向。** 明确当前有条件优先、调整或暂缓的礼品方案，以及成品、需求或资源仍未证实的部分。“保留讨论”不等于投入条件成立。
2. **代价。** 已有数据时写完整费用、贡献、与底线的差额，以及最早可售E、目标开售余量、购买覆盖。未知留未知。变化后重算，不能沿用旧数字。达到底线不证明较现状提高。
3. **唯一补证。** 只选一个能改变同一判断的事实。判断新客群接受时，优先核一条已有的完整方案接受反馈，分别看它有没有支持价格、数量、购买日期和到货要求；没有记载的字段仍未知。不要把一串独立问题当成一项。也可补同口径现有贡献并解释比较结果。
4. **答案如何改判。** 必须写出本轮适用的保留和改停条件，不能只有“若接受就继续／若不接受就暂停判断”。

| 反馈或变化 | 这次怎样判断 |
| --- | --- |
| 补证支持对应条件 | 只更新这一项，明确方向保留到讨论层；其他必要未知继续保留。价格接受不能清除数量、日期、成品要求的未知。 |
| 补证不支持，或新增价格、数量、成品要求 | 明确需调整哪项要求、收入或费用。用当前贡献底线说明是否还有空间；固定条件下无可行解，明确暂缓这个方案。 |
| 新要求影响准备或购买日期 | 用当前E、开售余量和购买覆盖重算；能与窗口相交才可有条件保留。余量小不等于完全来不及；无交集则暂缓本次窗口。 |

只有所有候选都违反已给定且不可改变的条件，且未知无论取什么值都不改变本次结论时，才可直接说“无需补证，已知冲突足以作答”，到此结束。不追加改窗口、提前某一路、换资源等未被询问的反事实路线。评论中的改进要求、费用未知或接受未知不属于这种确定无解。

最后只问选中的那一项；用户明确不再追问则只列待核与分支。用户不知道就保留当前条件判断，不转成让他去调研、联系或制作样品。不要把“暂停投入判断”当作调整或暂缓礼品方案的答案。
