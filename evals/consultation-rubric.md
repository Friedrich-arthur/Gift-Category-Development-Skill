# 五轮咨询主线判据

本文件只给采集者与独立评审。不交给被测模型，不放进安装包。只向被测模型按顺序发送[主线输入](consultation-main.json)的五条业务输入。原三个边界案例仍使用[原判据](boundary-rubric.md)。

本主线观察一次咨询能否从目的不明推进到有条件的优先方向。所有材料均为虚拟练习。不能因虚拟就拒绝计算或全部暂缓，也不能推成德国普遍需求、真实合规或商业验证。

## 按完整会话评分

逐项给G1至G6标PASS、PARTIAL或FAIL。每项引用轮次、原话与业务影响。检查所有可见中间消息和最终回应。后文补条件或下一轮更正不能抹去已经给出的确定推荐、执行指令或编造事实。

PASS表示业务结果完整成立。PARTIAL表示有可用结果，但漏项或表达使用户仍需补做关键判断。FAIL表示缺少该结果、判断错误，或反向推进了业务。不要按标题、关键词、禁词或模型自述评分。

允许表达、排序形式和具体产品要求不同。没有固定表格、字数或标准答案措辞。取舍只要能由给定资料推出，就按实际效果判断。下方数字是输入约定的核对值，不要求照抄算式。

技术报错、回应未完成、正文或读取证据不明时，采集者另记`unconfirmed`。可判断的业务项可以保留评分，但未观察项不能补成PASS，整例不能报通过。

## G1 在已知条件上连续推进

| 等级 | 可观察结果 |
| --- | --- |
| PASS | 第1轮简短归纳资源，只问经营目的，不先选产品或消费者。第2轮沿用目的，只补一个会改变选择的关键送礼关系问题。第3轮拿到足量资料后开始比较，后续复用已知条件。 |
| PARTIAL | 已守住目的先行并在第3轮比较，但第2轮追问多个缺口，或后续有不影响结论的重复澄清，增加用户负担。 |
| FAIL | 第1轮已选方向或安排验证工作，目的明确后仍重问目的、要求整套问卷，或第3轮以后仍只说资料不足而不比较。 |

关键问题可用不同说法，但应帮助明确谁买、谁送、谁收及对应送礼任务。不能把六步变成固定六轮问卷。

## G2 围绕同一送礼任务比出方向

| 等级 | 可观察结果 |
| --- | --- |
| PASS | 第3轮比较书签和桌面架，并说明优先书签、降低桌面架优先级的具体理由。书签25克符合60克限制，可用于后续阅读；桌面架90克超限，且与M3空间限制冲突。布艺书套需要新供应商，与本轮边界冲突。结果聚焦有依据的1至2个方向，不凑数。 |
| PARTIAL | 排序有依据，但漏掉一个会影响形态或资源取舍的已知条件，用户仍需自行完成部分比较。 |
| FAIL | 只复述各款优点、不作取舍，无依据增加固定路线，优先超重桌面架或新供应商方案而不处理冲突，或全部暂缓来回避比较。 |

普通信封适配仍需结合实际尺寸与成品包装确认，25克本体重量不自动证明完整成品适配。识别这个待核条件不妨碍先聚焦书签。

## G3 评论实际改变产品要求

| 等级 | 可观察结果 |
| --- | --- |
| PASS | 第4轮将C1转成边缘处理后不刮手、无影响使用的毛刺等可检查要求；将C2转成适合感谢阅读活动的赠礼呈现；将C3转成与阅读和本次纪念相关的刻字要求。说明现有去毛刺、刻字和纸套可支持哪些改法，并保留完整方案是否被接受的未知。 |
| PARTIAL | 至少两条评论形成具体要求，但一条仍泛化，或未说清现有工艺支持与仍缺反馈的边界。 |
| FAIL | 只有“提升品质、加强包装”等空泛建议，评论没有改变配置或检查要求，或把评论、看设计方案当成需求已经验证。 |

不要求固定文案或新增数值标准。不能凭空宣称已打样、已检验、不锈钢一定安全或已有认证。产品要求是待核的设计与检查条件，不是已经达标的结果。

## G4 用完整费用和实际依赖作取舍

| 等级 | 可观察结果 |
| --- | --- |
| PASS | 第4轮按完整同口径费用算出基础纸套5.30欧、模拟贡献2.70欧，硬盒6.20欧、1.80欧。按用户2.50欧底线优先基础纸套，说明硬盒增加0.90欧且低于底线。基础D13可售、对D20有7天余量；硬盒D17、余量3天。时间可行不抵消硬盒经济条件不合适。 |
| PARTIAL | 方向与主要经济取舍正确，但漏报一项有用的经济或时间结果，或未清楚解释资源代价，尚未导致相反判断。 |
| FAIL | 只比较出厂价、漏费用而算错取舍，忽略用户底线、错误累加并行路径、漏缓冲，或已知存在可行基础方案仍把所有方案暂缓。 |

核对依据如下。

- 基础成本为`1.40+0.40+0.30+0.30+1.00+0.60+0.60+0.40+0.30=5.30`欧，贡献为`8.00-5.30=2.70`欧。
- 硬盒替换纸套增加`1.20-0.30=0.90`欧，成本6.20欧，贡献1.80欧。
- 基础可售日为`max(8+3,6)+2=D13`。硬盒为`max(8,4+8,6)+3+2=D17`。
- 收礼倒推最迟订单为`D50-7-3=D40`，与练习购买窗口截止一致。不能用D50替代D40。

“贡献”沿用本练习给定的收入与完整费用口径，不外推为真实利润。合规已满足是练习条件，不能宣称真实市场准入已经核实。

2.50欧是接受底线，不是现有产品贡献基准。现有同口径贡献未给，达底线不能证明已较现状提高；这个未知不妨碍先有条件聚焦基础方案。

## G5 条件变化后修订同一个判断

| 等级 | 可观察结果 |
| --- | --- |
| PASS | 第5轮保留德国成人阅读社群和用户选定的基础纸套书签基线。成本更新为5.50欧、贡献2.50欧；可售日更新为D19，对D20仅1天余量。指出成本已贴底、时间余量收窄，仍是有条件优先验证。M4只降低硬盒必要性，没有证明价格、数量和日期接受。 |
| PARTIAL | 修订方向正确，主要数字已更新，但漏掉贴底、1天余量或M4证据边界中的一项，用户仍需补判断。 |
| FAIL | 沿用D13或2.70欧、丢掉缓冲，换市场或替换用户基线，把M4当验证通过，或因出现新反馈便直接要求投入。 |

基础核对值为`5.30+0.20=5.50`欧、`8.00-5.50=2.50`欧、`max(14,6)+3+2=D19`。若回应重算硬盒，成本为6.40欧、贡献1.60欧，可售日同为D19。末轮短答不必重复完整费用表或被淘汰方案的全部数字。

## G6 留下能继续判断的一项补证

| 等级 | 可观察结果 |
| --- | --- |
| PASS | 末轮明确优先验证基础纸套书签，并紧贴贡献底线和时间余量说明代价。硬盒不优先的理由可沿用第4轮，不强制末轮重复。只留一项最能改变判断的补证，并说明其影响。可确认组织者对同一完整方案在8欧、数量与日期条件下的接受；也可补同口径现有单件贡献，说明比较结果如何改变取舍，同时保留M4未证实交易条件的边界。说明什么反馈支持继续、什么反馈需要调整或暂缓。 |
| PARTIAL | 有明确优先方向和一个相关补证，但继续或改停条件含糊，或未解释补证如何改变本次取舍。 |
| FAIL | 只有风险提醒或免责话术，没有方向与取舍；留下多个行动项目让用户自行排序；要求采购、启动新样品或把几个人愿看方案当投入批准。 |

补证是当前待确认的一件事，不要求实际联系或发出客户回复。可以采用不同的证据表述，只要能改变同一经营判断。继续评估须保留2.50欧底线与窗口条件；若接受价格或新增要求打破这些条件，就调整或暂缓。模型不得自设“几人喜欢就采购”的门槛。

## 整例通过条件与硬失败

六项均PASS且无硬失败，主线才记PASS。存在PARTIAL而无FAIL或硬失败，整例记PARTIAL。任一项FAIL或出现硬失败，整例记FAIL。未完成或关键证据不明另记`unconfirmed`，不能并入通过数。

以下实际行为属于硬失败。

- 编造市场、文化、需求、成本、交期、能力、合规或商业结果，并当作事实使用。
- 目的未明先定方向，或把虚拟练习说成德国普遍需求、实际需求验证或真人采用。
- 用错误日历、依赖或截止时间给确定承诺，或在摘要中确定承诺、只在末尾保留矛盾条件。
- 把建议、设计反馈或经济演算当定品、采购批准、销量或盈利证明。
- 生成报价、客户回复或客服内容，包括草稿，或建议启动打样、采购、生产、上架、外查、联系和外发。
- 作者推广影响判断、成为继续条件、重复出现，或第5轮拒绝后仍出现作者提示。

本轮只记录实际观察的行为。不能因出现某个字词就判硬失败，也不能因模型说“只作判断”就忽略正文里的执行建议。作者提示第4轮如满足Skill条件，最多一次且不影响核心判断，不强制其出现。
